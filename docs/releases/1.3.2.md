## Voice Recorder 1.3.2

Versión de mantenimiento: dependencias actualizadas, sin cambios de funcionamiento.

### Dependencias

- NAudio 2.4.0 (captura de audio), Microsoft.ML.OnnxRuntime 1.32.0, Microsoft.Data.Sqlite 10.0.15 y Velopack 1.2.161.
- Herramientas de pruebas: Microsoft.NET.Test.Sdk 18.12.0, xunit.runner.visualstudio 4.0.1 y coverlet 10.1.1.
- GitHub Actions actualizadas a sus versiones mayores actuales.

### Instalación

Si la instalaste con **VoiceRecorder-win-Setup.exe**, la app ofrecerá *Actualizar y reiniciar* (o pulsa **Buscar actualizaciones**). Con Scoop: `scoop update voice-recorder`. También está disponible **VoiceRecorder-win-Portable.zip**.

Requiere Windows 10 2004+ o Windows 11 de 64 bits.

## Voice Recorder 1.7.0

### Resumen con IA

- **Genera un resumen de cada llamada** con OpenAI: resumen breve, puntos clave, decisiones, tareas (con responsable si se menciona) y preguntas abiertas. Se envía solo el texto de la transcripción y las notas de la sesión, **nunca el audio**, con tu clave de OpenAI.
- **Por defecto se pide a mano**: abre la sesión y pulsa **Generar resumen** (o *Regenerar resumen* para reemplazarlo). El resumen aparece arriba de la conversación, en un panel plegable.
- **Resumen automático opcional**: en **Configuración › Resumen…** puedes activar que se genere solo al terminar cada transcripción. Ahí eliges también el modelo (por defecto `gpt-5-mini`) y su precio, para estimar el coste.
- El coste de cada resumen aparece en **Costes…** como «OpenAI (resumen)».
- La exportación a **TXT** y **Markdown** incluye el resumen (y el análisis, si lo hay).

### Subir a Notion

- **Nuevo destino: tu base de datos de Notion.** Configúralo en **Configuración › Notion…** con el token de tu integración interna y el enlace de la base de datos; *Probar conexión* comprueba el acceso sin crear nada.
- **Al terminar una transcripción la app pregunta si quieres subir la sesión.** Nunca sube nada sin confirmación, y puedes desactivar la pregunta.
- También puedes subir cualquier sesión con **Subir a Notion** desde su chat, que después muestra el enlace *Ver en Notion*.
- Cada sesión es una página con el título y, si la base de datos las tiene, las propiedades **Fecha**, **Etiquetas** y **Duración**. Dentro van las notas y lo que elijas (ver abajo); la transcripción y el análisis, en encabezados plegables. El audio no se sube.
- Si vuelves a subir una sesión, se crea una página nueva y la anterior se mueve a la papelera de Notion.
- **Eliges qué se sube** en **Configuración › Notion…**: resumen, transcripción completa y/o análisis de comunicación. Puedes marcar uno, otro o varios; la pregunta al terminar indica qué se va a subir.
- El token se guarda cifrado con DPAPI para tu usuario de Windows.

### Análisis de comunicación (experimental)

- **Nueva sección Experimental** en Configuración, desactivada por defecto.
- **Analizar conversación** (en el chat de cada sesión) evalúa cómo condujiste la llamada con ocho criterios de buenas prácticas: escucha activa, interés por el otro, reconocimiento, tono, manejo del desacuerdo, empatía, persuasión colaborativa y forma de pedir o dar feedback.
- Estructura fija: valoración general, criterios con puntuación y evidencia, aciertos, fallas, mejoras con frases alternativas y prioridades para la próxima llamada.
- Nunca es automático: se genera cuando lo pides y se puede regenerar con *Reanalizar conversación*. Solo se envía el texto a OpenAI, nunca el audio. Su coste aparece en **Costes…** como «OpenAI (análisis)».

### Sincronización

- **Sincronizar…** muestra, además de lo que falta subir o bajar, si cada sesión está transcrita, tiene resumen, está analizada y se subió a Notion, con filtros para encontrar las pendientes.

### Aviso legal y privacidad

- **Aviso legal y privacidad actualizados** (revisión 2026-11-24.2): recogen el envío del texto a OpenAI para los resúmenes y el análisis de comunicación, y la subida opcional a Notion. La app pedirá aceptarlos de nuevo al abrirla.

### Mantenimiento

### Instalación

Si la instalaste con **VoiceRecorder-win-Setup.exe**, la app ofrecerá *Actualizar y reiniciar* (o pulsa **Configuración › Buscar actualizaciones**). Con Scoop: `scoop update voice-recorder`. También está disponible **VoiceRecorder-win-Portable.zip**.

Requiere Windows 10 2004+ o Windows 11 de 64 bits.

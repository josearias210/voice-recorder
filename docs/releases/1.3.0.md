## Voice Recorder 1.3.0

### Novedades

- La versión de la aplicación se muestra en la barra de estado («v1.3.0 · instalada» o «v1.3.0 · portable»), en el título de la ventana y en el menú de la bandeja del sistema.
- Botón **Buscar actualizaciones** para comprobar a demanda si hay una versión nueva en GitHub Releases, con mensaje de resultado (al día, sin conexión o portable).

### Mejoras

- Actualizaciones incrementales: el release vuelve a generar el paquete delta a partir de la versión anterior, así que actualizar desde la 1.2.0 descarga solo lo que cambia.
- Scoop: el manifest crea correctamente el acceso directo del menú Inicio e incluye `checkver`/`autoupdate`.
- Winget: manifests listos para la 1.2.0 y la 1.3.0; el script de generación toma el SHA256 directamente de GitHub sin descargar el instalador.
- Dependencias de test actualizadas (xUnit 2.9, Test SDK 17.12).

### Instalación

1. Descarga y ejecuta **VoiceRecorder-win-Setup.exe** para instalar o actualizar. Si ya tienes la 1.2.0 instalada con Setup, la app ofrecerá *Actualizar y reiniciar* al arrancar (o pulsa **Buscar actualizaciones**).
2. Abre VoiceRecorder desde el menú Inicio y descarga el modelo de transcripción si hace falta (Base Q5: unos 60 MB).

Requiere Windows 10 2004+ o Windows 11 de 64 bits. El runtime .NET está incluido.

También está disponible **VoiceRecorder-win-Portable.zip**: descomprímelo y ejecuta `VoiceRecorder.exe`. La auto-actualización integrada requiere Setup; el portable se actualiza manualmente y Scoop mediante `scoop update voice-recorder`.

Los modelos, preferencias y sesiones se guardan en `%LOCALAPPDATA%\VoiceRecorder` y se conservan al actualizar.
